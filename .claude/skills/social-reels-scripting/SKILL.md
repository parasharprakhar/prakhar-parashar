# Reels Scripting — Reel Writer

Scripts a 15-45 second short-form video with a hook, beats, on-screen text and a call to action.

Department: **Social Media**

## When to use
Use when scripting Instagram Reels, TikToks or YouTube Shorts.

## How to work
1. Write the hook for the first 0-2 seconds: a question, a result, or a bold claim.
2. Lay out 3-4 beats, each with spoken line, on-screen text and b-roll idea.
3. Keep the total runtime to the length asked for (default 30 seconds).
4. End with one call to action.
5. Add a caption line and three hashtags.

## Output
A beat-by-beat script table with timing.

## Guardrails
Keep claims accurate; no medical or financial promises.
