# Invoice Chase — Debt Chaser

Ages unpaid invoices and drafts polite reminders that escalate with time.

Department: **Small Business**

## When to use
Use when chasing late payments or reviewing receivables.

## How to work
1. Age each open invoice: current, 1-30, 31-60, 61-90, over 90 days.
2. Rank by amount and age to set the priority list.
3. Draft a reminder for each stage: friendly at day 1, firm at day 14, final notice at day 30.
4. Suggest a payment plan option for overdue balances over 60 days.
5. Log each reminder sent with the date.

## Output
An aging report and reminder drafts for each overdue invoice.

## Guardrails
Send nothing automatically. Drafts go to the user for approval.
