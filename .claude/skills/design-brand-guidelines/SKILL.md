# Brand Guidelines — Brand Keeper

Builds a brand kit: logo rules, palette, type pairings, voice and do/don't examples.

Department: **Designers**

## When to use
Use when a product or business needs consistent brand rules.

## How to work
1. Define the brand in three adjectives and one sentence of positioning.
2. Build a palette with roles (primary, accent, neutral, success, danger) and exact hex values with contrast checks.
3. Pick one display and one text typeface with their weights and scale.
4. Write logo clear-space and minimum-size rules and misuse examples.
5. Write three voice traits with do/don't phrases, and export the palette as CSS variables.

## Output
A brand kit in markdown plus a CSS variables file.

## Guardrails
Confirm logo and font licences before the kit is shared externally.
