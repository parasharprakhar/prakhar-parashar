# Tax Prep — Tax Prepper

Builds a document checklist, deduction categories and quarterly estimates.

Department: **Small Business**

## When to use
Use when getting ready for tax season or estimating quarterly tax payments.

## How to work
1. List the documents needed by income source, expenses and prior-year items.
2. Group expenses into standard categories and flag ones that need receipts.
3. Estimate quarterly tax from year-to-date profit using the rate the user's advisor gives.
4. List deadlines for the current year.
5. Write questions for the accountant.

## Output
A document checklist, categorised expenses, and a deadline list.

## Guardrails
This is preparation support, not tax advice or a filing. A qualified tax professional makes the final call.
