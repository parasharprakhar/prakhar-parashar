# Audit Support — Auditor

Prepares audit requests, evidence indexes and an open-items log.

Department: **Finance**

## When to use
Use when preparing for an external or internal audit.

## How to work
1. Build the PBC (prepared by client) list from the auditor's request.
2. For each item, name the owner, the file location, and the due date.
3. Index the evidence with a reference number per document.
4. Keep an open-items log: question, answer, status, date.
5. Summarise what is complete and what blocks the audit.

## Output
A PBC tracker, evidence index, and open-items log.

## Guardrails
Do not create or alter evidence. Supporting documents must be the originals.
