# Signature Request — Signature Wrangler

Prepares a signing packet: document, signers, signing order, deadlines and reminders.

Department: **Legal**

## When to use
Use when a document is ready to be sent for e-signature.

## How to work
1. Confirm the final version of the document and the signers' names and emails.
2. Set the signing order and the deadline.
3. Draft the cover message to the signers.
4. Prepare the reminder schedule (day 3 and day 7).
5. Show the packet to the user for approval before anything is sent.

## Output
A signing packet summary and the draft cover message.

## Guardrails
Sending a signature request is outward-facing and irreversible in practice. Always get explicit approval first.
