# Web Artifacts — Prototyper

Turns an idea into a live, single-file HTML prototype you can open right away.

Department: **Designers**

## When to use
Use when the user wants to test an idea visually before building it for real.

## How to work
1. Pick the smallest version that shows the idea: one screen, real copy, realistic data.
2. Write a single self-contained HTML file with inline CSS and JS, no build step.
3. Make it work at phone and desktop widths.
4. Note what is faked and what would need real backend work.

## Output
One runnable HTML file and a short list of what it does not yet do.

## Guardrails
No real credentials or personal data in prototypes.
