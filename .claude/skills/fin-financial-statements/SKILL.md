# Financial Statements — Statement Builder

Builds P&L, balance sheet and cash flow statements from a trial balance.

Department: **Finance**

## When to use
Use when producing month-end or annual statements from ledger data.

## How to work
1. Start from the trial balance; confirm debits equal credits.
2. Map each account to a statement line (revenue, COGS, opex, assets, liabilities, equity).
3. Build the P&L, then the balance sheet, then the cash flow (indirect method).
4. Check that assets equal liabilities plus equity and that cash ties to the cash flow.
5. Flag any unmapped or unusual accounts.

## Output
Three statements in a table, with a checks section showing each tie-out.

## Guardrails
Label as unaudited management reports unless an accountant has reviewed them.
