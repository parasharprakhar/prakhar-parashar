# Script Template — 30-second Short

Speaking pace is about 2.5 words per second, so a 30-second video is about 70–75 words of voiceover.

**Title:** ____  **Topic:** ____  **Hook pattern:** question / bold claim / story / number / contrarian
**Source for the main fact:** ____ (study, book, or article; required)

| Time | Beat | Voiceover (words) | On-screen text | Visual (footage keywords) |
|---|---|---|---|---|
| 0–2s | HOOK | (max 12 words) | (max 4 words, large) | |
| 2–8s | Setup: why this matters to the viewer | (about 15 words) | | |
| 8–20s | Payoff: the fact or explanation, in 2–3 short steps | (about 30 words) | | |
| 20–27s | Twist or example the viewer can try | (about 17 words) | | |
| 27–30s | Loop or call to action (ties back to the hook, or "follow for more") | (under 8 words) | | |

## Checks before recording
- [ ] First 2 seconds are visually and verbally interesting.
- [ ] Every claim has a source.
- [ ] Voiceover is under 75 words.
- [ ] On-screen text is readable at phone size.
- [ ] The video is different from the last 3 (topic, structure, visuals).
- [ ] Footage, music and voice are licensed or royalty-free.
